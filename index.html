Guía: Sincronizar Google Classroom

KOOBA puede conectar tu cuenta de Google para importar tareas de Classroom. El valor de XP se calcula automáticamente y, para tareas reales de Classroom, la recompensa se entrega cuando Google confirma la entrega.

1

Opción 1: Prueba Rápida (Modo Demo)

Haz clic en el botón verde "Sincronizar Classroom" arriba a la derecha. Cargará asignaciones reales de prueba directamente a la columna Classroom para explorar el sistema de puntos.

2

Opción 2: Conectar tu Cuenta Real de Estudiante

Sigue estos sencillos pasos para vincular la API oficial de Google:

  1. Abre Google Cloud Console.
  2. Crea un proyecto nuevo (ej. "Mi Kanban Escolar").
  3. En la sección Bibliotecas de APIs, busca y activa Google Classroom API.
  4. En Pantalla de consentimiento OAuth, selecciona "Usuarios externos" y agrega tu correo de estudiante.
  5. En Credenciales, crea un ID de cliente de OAuth 2.0 (Tipo: Aplicación Web).
  6. Copia tu Client ID, abre el icono de engranaje ⚙️ de esta app, pégalo y cambia el modo a Google API Real.

Seguridad Garantizada

Este prototipo usa OAuth de Google en el navegador. En la versión pública de KOOBA, la sesión, XP y reglas de recompensas deben validarse también desde el servidor.
